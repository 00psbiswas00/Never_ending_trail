Which logo, where
01 Primary logo, horizontal ... the default: website, documents, merch
02 Secondary logo, stacked .... square spaces, posters, T-shirts
03 Alternate, bilingual ....... English with the Bangla name
04 Alternate, Bangla first .... Bengali posts and events
05 Brand mark ................. the mark alone: patch, stamp, end cards
06 Social, compact ............ every profile picture (use the 1080 avatar), YouTube watermark
07 Favicon, micro ............. browser tab, bookmarks, phone home screen
08 Patches .................... embroidered patches (see below)

Colourways
colour ... full colour, for cream or white backgrounds
reverse .. full colour, for indigo #23325E backgrounds (transparent file, looks empty on white)
indigo ... one colour, single-ink print, emboss, partners
ink ...... one colour, rubber stamps (mark only)
white .... one colour, over photos and video

File types
SVG ... screen and web (scales to any size)
PNG ... ready-to-post images, transparent background
PDF ... print (colour and indigo versions)

Text in every lockup is converted to outlines, so no fonts are needed to open them.
Minimum sizes and clear space: see the Brand Book.

Patches (folder 08, sizes are the stitched size, each in cream and indigo, indigo merrowed edge)

main-bangla-80mm (cream/indigo) .. the same with the Bangla name

round-100mm (english/bangla) ..... round badge, name around the edge
stacked-100x112mm ................ stacked logo patch

Thread: four colours, indigo #23325E, cream #F1E9D8, red #C9372C, turmeric #E3A21A.
Ask the maker to match these to their nearest thread shades.
Indigo merrowed or satin edge. Send the PDF or SVG; the maker digitises from it.
